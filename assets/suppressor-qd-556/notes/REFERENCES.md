# Sources (cited, not committed)

Nothing listed here is in this repository. The numbers taken from each source are in `sim/README.md` and
`sim/checks.json`, each with its status (calibration target, prediction, bound).

## There is no reference image

This is a generic suppressor by brief: no product was photographed, measured or traced, and no reference image was
chosen. The shape is an engineering layout built from class figures (below) and from the HK416 muzzle device it has
to fit. So the reference-to-3D process (decompose a chosen image, then rebuild it) has nothing to decompose here; what
stands in for it is the recipe's own fit and volume checks (`model/inventory.json`, `model/build_stats.json`) and the
owner's review of the renders, which has not happened yet.
