# Renders

Renders of a local build of `model/build.py` (`model/tools/render.py`), flat materials, no textures.

`compare_right.jpg` includes the reference photo: Wikimedia Commons, `File:Mossberg 590.jpg`,
https://commons.wikimedia.org/wiki/File:Mossberg_590.jpg, by the U.S. Bureau of Alcohol, Tobacco, Firearms and
Explosives. **Public domain** (a work of the US federal government). The numbers behind it are in
`model/compare.json`; what it does and does not show is in `notes/COMPARE.md`.

| File | View |
|---|---|
| `compare_right.jpg` | Reference, model in the same pixel grid, difference map |
| `right.jpg`, `left.jpg`, `top.jpg` | Orthographic. Only the right side has a reference |
| `three_quarter.jpg`, `first_person.jpg`, `first_person_hip.jpg` | Perspective |
| `closeup_right_receiver.jpg`, `closeup_left_receiver.jpg` | Receiver and controls |
| `action_open.jpg` | Slide and bolt at the rear of the stroke |
| `exploded.jpg` | The manual's field-strip assemblies |
