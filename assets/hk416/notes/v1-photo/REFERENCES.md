# Reference sources (cited, not committed)

The shape was measured from these images. None of them is in this repository: their licences either don't allow it
or haven't been checked. Keep local copies in `refs-local/` (ignored by git) if you rebuild or re-check the model.
`model/build.py` and `model/tools/make_notes.py` give every traced outline in the pixel coordinates of
`profile-right-photo.png`, so each number can be checked against that image.

| File the recipe names | What it shows | Source |
|---|---|---|
| `profile-right-photo.png` | Right side, muzzle right, studio photo. Primary silhouette and the ruler for every dimension. | Supplied by carpetshark. |
| `profile-both-sides-drawing.jpg` | Two-sided drawing: left side on top, right side below. | Wikimedia Commons, Category: Heckler & Koch HK416. |
| `profile-left-photo-416N.jpg` | Left side of an HK416N (its optic and grip ignored). Left-side controls and the stock. | Wikimedia Commons, Category: Heckler & Koch HK416. |
| `closeup-right-receiver.jpg` | Ejection port, dust cover, bolt, selector marks (.22 LR replica). | lynxdefense.com, HK416 .22 LR review. |
| `closeup-left-lower-controls.jpg` | Selector, pictograms, bolt catch, pins (.22 LR replica). | lynxdefense.com, HK416 .22 LR review. |
| `closeup-front-sight.jpg` | Folding front sight, rail slots and numbers (.22 LR replica). | lynxdefense.com, HK416 .22 LR review. |
| `closeup-rear-sight-charging-handle.jpg` | Folding rear sight, charging handle and latch (.22 LR replica). | lynxdefense.com, HK416 .22 LR review. |
| `closeup-handguard-front.jpg` | Handguard front, barrel and flash hider (.22 LR replica). | lynxdefense.com, HK416 .22 LR review. |

The close-ups show a replica with a slim handguard; they were used only for small details the AR pattern shares.
Where they differ from the profiles, the profiles win.
